Factory Inventory Management — Architecture

A full-stack inventory management demo: Vue 3 single-page app on the frontend, a FastAPI service on the backend, and JSON files standing in for a database. No persistence layer — everything is loaded into memory at server startup.

Tech Stack

Frontend

Vue 3 + Vite

  • Vue 3 (Composition API)
  • Vue Router
  • Axios (HTTP client)
  • Vite (dev server / bundler)
localhost:3000
Backend

Python + FastAPI

  • FastAPI (routing)
  • Pydantic (validation)
  • Uvicorn (ASGI server)
  • uv (dependency management)
localhost:8001
Data

In-Memory JSON

  • 7 JSON files in server/data/
  • Loaded once at startup
  • No database — changes reset on restart
server/mock_data.py

System Architecture

Request & Data Flow

1

Filter change

User adjusts Time Period, Warehouse, Category, or Order Status in FilterBar.vue.

→
2

Composable state

useFilters.js updates shared filter state consumed by the active view.

→
3

API request

api.js sends filters as query params via axios to FastAPI.

→
4

Server filtering

FastAPI filters the in-memory dataset and validates the response against Pydantic models.

→
5

Reactive render

Raw data lands in refs (allOrders, inventoryItems); computed properties derive the view.
